CLI 오류·한도·로그인 불일치는 가짜 CLI 자식 프로세스로 재현했다. 실제 계정의 로그인 상태를 바꾸거나 사용 한도를 소진하지 않았다. 렌더링 테스트는 실제 Chromium을 사용하고, 네이티브 이미지 provider의 실패·취소는 통제한 fixture로 검사했다.

## 실제 구독 CLI 확인

API 클라이언트나 API 키를 사용하지 않고 설치된 CLI의 ChatGPT 인증으로 다음을 실행했다.

- 작은 비대화형 구조화 응답: stdin, `read-only`, 출력 스키마, JSONL 이벤트와 별도 최종 파일을 확인했다.
- PostgreSQL B-tree의 유한한 과정 초안: 35분 파트 한 개의 목표·범위·파트를 생성하고 로컬 스키마로 검사했다.
- 전체 교재: 섹션 6개, Mermaid 도식 2개, 퀴즈 3개와 출처를 생성했다. 검사한 정의를 실제 저장·렌더링 경로에 넣고, 저장 교재를 TUI에서 다시 열었다.
- 네이티브 이미지: CLI의 이미지 도구로 실제 PNG를 생성·수집했다. 앱 어댑터의 최종 인자와 파일 검사를 거쳐 1,054,449바이트 PNG를 확인했다. 생성 이미지가 필요한 경우의 provider 연결은 렌더링 테스트로 별도 확인했다.

처음 생성한 교재에는 일본어 설명이 섞였다. 프롬프트 강화만으로 해결되지 않아 narrative 필드의 가나 제외 패턴과 로컬 검사, 실패 안내를 추가했다. 같은 교재 입력으로 한정된 QA 수정 호출을 실행해 한국어 교재를 확보하고 검증했다. 요약에 남은 수정 작업 지시 한 문장은 QA 샘플에서 수동으로 제거했다. 문서용 화면·PDF는 이 최종 샘플을 사용한다. 앱에는 자동 번역이나 추가 AI 재시도 경로를 넣지 않았다.

이 검사는 모든 언어 혼재를 판별하는 일반 언어 감지기가 아니다. 영어 기술 용어·코드·출처 제목은 허용하며 가나 혼입을 대상으로 한다. 생성 내용을 모두 사실 검증했다고 주장하지 않는다. Codex의 구독 사용 한도와 네이티브 이미지 사용량은 그대로 적용된다. [공식 인증 안내](https://learn.chatgpt.com/docs/auth), [이미지 생성 안내](https://learn.chatgpt.com/docs/image-generation).

## PDF 시각 검증

최종 실제 교재로 만든 A4 PDF **10페이지 전체를 PNG로 렌더링해 직접 확인**했다. 한글 본문, 코드 줄바꿈, 표, 흑백 도식, 제목·본문 배치와 페이지 경계를 확인했고 추출 텍스트에서 가나 혼입이 없음을 확인했다. 퀴즈는 **8페이지**, 정답·해설은 별도 **9페이지**에 있다.

긴 코드와 한글 Mermaid, 이미지 실패 → Mermaid 실패 → 저장된 ASCII를 포함하는 별도 검증 PDF도 **4페이지 전체를 확인**했다. ASCII의 줄·공백과 대체 이유를 보존했고 문제 3페이지·정답 4페이지의 분리를 확인했다. TUI와 PDF는 같은 `Lesson`과 선택된 자산을 사용한다.

README의 [PDF 이미지](assets/pdf-preview.png)는 최종 실제 교재의 2페이지이다. 전체 PDF와 교재 JSON·작업 로그는 로컬 학습 데이터로 보관하며 저장소에 넣지 않았다.

## 화면 캡처의 근거

아래 이미지는 구현한 `StudyApp`을 Textual `run_test(size=(124, 42))`에서 실행하고 실제 위젯 조작·저장 상태로 얻은 화면 export를 PNG로 변환했다. UI 목업이나 AI가 그린 스크린샷이 아니다. 최종 기능 QA 후 캡처했으며 모든 PNG를 직접 확인했다.

| 파일 | 실제 화면 상태 |
| --- | --- |
| [lesson.png](assets/lesson.png) | 실제 구독 생성·QA한 PostgreSQL 교재를 저장 후 다시 열어 첫 섹션을 읽음. 추가 AI 호출 없음 |
| [plan.png](assets/plan.png) | 고정 데모 과정의 제목·목표·범위·파트를 일반 텍스트로 편집 |
| [ascii-fallback.png](assets/ascii-fallback.png) | 실제 Mermaid 렌더러의 제한 시간을 짧게 설정해 실패시킨 뒤 저장된 ASCII 후보 표시. caption·대체 이유·원본 재시도 버튼 확인 |
| [quiz.png](assets/quiz.png) | 고정 데모의 정답을 공개한 저장 상태에서 해설·후속 주제·다음 선택 표시 |

첫 PNG 변환에서는 한글·강조·inline code의 간격이 어긋났다. 설치된 Rich의 SVG export가 `textLength`에는 문자 수를, 다음 span의 x 좌표에는 터미널 셀 수를 사용해 한글 두 칸의 길이가 일치하지 않는 원인을 확인했다. 변환 단계에서 원본 x/y·스타일·셀 폭을 유지하고 각 글리프를 Rich의 표시 셀 좌표에 놓았으며, 번들 고정폭·한글 폰트로 다시 렌더링했다. 이는 캡처 인코딩의 수정이며 앱 코드나 화면 내용을 바꾸지 않았다. 본문·강조·inline code·한글·ASCII의 정렬과 가독성을 최종 PNG에서 확인했다.

## QA에서 수정한 문제

- 마지막 파트를 먼저 선택하면 앞 파트를 건너뛰어 과정이 완료되던 경로를 수정했다. 완료 선택은 현재 파트만 마치고 남은 미완료 파트로 이동한다.
- 완료 과정의 복습 파트 선택을 기억하고 완료 상태를 유지하도록 수정했다.
- 취소·실패한 첫 생성은 저장 과정에서 수동으로 재시도할 수 있다. 재생성 실패는 기존 교재를 유지한다.
- 화면 교체 중 사라진 Select의 지연 이벤트를 무시하고 위젯 교체·repaint를 묶어 화면 전환을 안정화했다.
- 부모가 먼저 종료한 CLI의 남은 자손 프로세스도 timeout·취소 시 정리하도록 수정했다. POSIX 프로세스 그룹의 실제 heartbeat 중단을 확인했다.
- CLI의 `format: uri` 미지원은 전달 스키마에서만 제거하고, 전체 로컬 스키마의 URI 검사는 유지했다. 오류 이벤트 뒤 성공 이벤트가 와도 실패로 처리한다.
- 본문 언어 혼재를 거부하고, 최종 교재의 한국어 PDF·실제 TUI 화면을 확인했다.

## 남은 검증 경계

- Linux·Windows에서 OS 뷰어 호출과 자식 프로세스 정리를 실제 기기로 확인하지 않았다.
- CLI 동작과 기본 모델·사용 한도는 설치 버전·계정에 따라 달라질 수 있다. 0.160.1에서 확인했으며 앱은 모델을 고정하지 않는다.
- 생성 교재의 구조·참조·출처 URL 형식 검사는 사실 정확성이나 링크의 장기 유효성을 보증하지 않는다. SQL 예제는 데이터베이스에 실행하지 않았다.
- 제시된 30~45분은 계획·교재 분량의 계약이다. 실제 학습자의 소요 시간에 대한 사용자 실험은 하지 않았다.
- 네이티브 PNG 생성 성공만으로 모든 그림의 교육적 적합성·인쇄 가독성이 보장되지는 않는다. 첫 버전 PDF는 파트별이며 전체 과정 합본은 제외한다.
- 번들 외부 자산은 해당 MIT·SIL OFL 라이선스를 별도로 유지한다. 출처·라이선스는 [NOTICE](../src/study_tui/assets/NOTICE.md)에 있다.
