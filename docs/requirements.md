# 요구사항

## 확정 제품 요구사항

### 목적과 주제 입력

- 소프트웨어 엔지니어가 DB 인덱스, 소프트웨어 디자인·아키텍처 등 하나의 백엔드 주제를 단계별로 공부하는 개인용 로컬 학습 도구다.
- 프런트엔드 개발 부담을 줄이기 위해 TUI를 사용한다. 별도 웹 UI나 네이티브 앱 UI는 범위에 없다.
- 주제는 사용자가 직접 입력한다. 다른 GPT 대화에서 추천받은 주제를 입력할 수 있다.
- 앱 안의 이력서 업로드·분석이나 학습 주제 추천은 구현하지 않는다.

### 과정과 파트

- 주제를 입력하면 AI가 학습 목표와 과정 초안을 제시한다. 사용자가 필요하면 조정하고 시작한다.
- 시작부터 긴 목적·난이도 설문이나 진단 시험을 강제하지 않는다.
- 기본 과정은 목표와 범위를 정하고 완료 지점을 둔다.
- 파트는 사용자의 다음 선택으로 완료 표시하며, 모든 확정 파트가 완료되면 기본 과정을 완료한다. 파트 선택으로 뒤의 파트에 먼저 들어가도 앞의 미완료 파트를 자동 완료하지 않는다.
- 한 파트는 30~45분 분량이며 개념, 동작 원리, 실무 예시, 시각자료, 간단한 퀴즈를 포함한다.
- 파트 끝에는 관련 심화 주제와 그 주제를 공부할 이유를 후보로 제시한다.
- 사용자가 선택할 때만 별도 후속 과정으로 이어간다. 기본 과정을 자동으로 끝없이 확장하지 않는다.
- 생성된 자료와 진행을 저장하고 중단 후 재개하는 기능을 기본 설계에 포함한다.

### 화면·시각자료·PDF

- 화면에서 학습 자료를 볼 수 있어야 하며, 인쇄용 PDF 내보내기는 필수다.
- 첫 버전 PDF는 **파트별**이다. 전체 과정 합본은 첫 버전 범위가 아니다.
- PDF에 본문, 실무 예시, 시각자료, 퀴즈 문제를 넣는다. 정답·해설은 문제와 분리된 영역/페이지에 두어 풀이 전에 보이지 않게 한다.
- 시각자료는 필수다. 개념별 다이어그램, SVG와 필요한 생성 이미지·삽화를 적절히 혼합한다.
- Mermaid, draw.io 등은 상황에 맞게 활용할 수 있다. 모든 도구를 동시에 통합할 필요는 없다.
- 본문에서 그림의 의미를 설명하고 연결한다. 한글, 글자 크기, 선명도, 페이지 나눔, 코드 줄바꿈, 흑백 가독성을 고려한다.
- 이미지 생성·그림 렌더링 실패 시 의미를 보존하는 Mermaid/SVG 또는 ASCII 도식으로 대체한다. Mermaid도 렌더링할 수 없으면 ASCII를 TUI와 PDF 양쪽에서 고정폭 텍스트로 표시한다.
- 대체 사실과 선택적 원본 재시도를 안내한다. 각 필수 그림의 원본 또는 의미를 보존한 대체 하나가 완성되면 자료 ready 조건을 충족한다. 대체도 모두 실패하면 이전 자료를 유지하고 미완성/재시도를 안내한다.
- ASCII의 줄·공백을 보존하고 구조·연결·순서·라벨을 본문과 맞춘다. 코드·도식이 인쇄 폭을 넘지 않도록 한다.
- 대체 후보는 본문과 함께 저장한다. 로그인·구독 한도·네트워크 문제로 AI 전체 호출이 불가능하면 저장된 검증된 정의만 사용하거나 재시도를 안내하며, 새 AI 대체 생성·유료 API 전환·무제한 재시도를 하지 않는다.

### 퀴즈

- 간단한 이해도 확인용이다. 문제 제시 → 사용자 풀이 → 정답 바로 확인 → 사용자 복습/다음 선택으로 진행한다.
- 앱에서 간단히 답을 입력하거나 종이에서 풀 수 있다. 사용자가 원하면 정답을 바로 확인한다.
- 복습하거나 다음 파트로 갈지는 사용자가 직접 판단한다.
- 자동 채점, AI 답안 평가, 점수 통과 조건, 강제 재시험, 적응형 보충 과정은 제외한다.

### 기본 흐름

1. 주제 직접 입력
2. AI 학습 목표·과정 초안 제시
3. 사용자 검토·필요한 조정·시작
4. 파트별 학습 자료·시각자료 생성 및 화면/PDF 열람·인쇄
5. 이해도 체크 퀴즈 풀이·정답 확인
6. 사용자 복습/다음 선택, 진행 저장·중단/재개
7. 기본 과정 완료
8. 사용자가 선택한 심화 주제로 새 과정 시작

## 확정 기술·비용 조건

- **언어·TUI:** Python과 Textual을 사용한다. Java/Spring 경험에 맞출 필요는 없다.
- **AI:** 로컬 자식 프로세스로 Codex CLI를 호출한다. 기존 ChatGPT/Codex 구독 인증을 사용하며 구독 한도는 적용된다.
- **과금:** 별도 API 비용을 원하지 않는다. 첫 버전 기본 연동은 Responses API가 아니며, API key 인증이나 유료 이미지 API로 자동 전환하지 않는다.
- **실행 구조:** 개인용 로컬 앱으로 별도 HTTP 백엔드 서버를 만들지 않는다. AI 실행은 원격 Codex 서비스에 의존하므로 오프라인 AI로 설명하지 않는다.
- **인증·설정:** 글로벌 Codex/Git 설정과 사용자 인증을 변경하지 않는다. 인증 파일·토큰을 앱 저장소로 복사하지 않는다.

## 설계 기본 선택

다음은 사용자 요구를 구현하기 위해 LLD에서 채택한 기본 설계다. 사용자가 개별 도구를 각각 확정했다는 의미는 아니다. 채택 근거·구체적 계약은 [상세설계](lld.md)에 있다.

- **저장:** SQLite에 진행·메타데이터, 로컬 파일에 본문·시각자료·PDF를 저장한다.
- **PDF:** HTML/CSS 인쇄용 교재 템플릿과 Playwright/Chromium을 사용한다. HTML/CSS는 웹 UI가 아니다.
- **화면 열람:** TUI에서 본문·그림 설명·퀴즈를 보고, PDF·이미지는 OS 뷰어로 연다.
- **시각자료:** Mermaid/SVG를 기본 경로로 두고 필요한 생성 삽화는 구독 경로에서 검증 후 연결한다.
- **검색:** 개념 설명은 cached, 최신 확인이 필요한 자료는 호출 단위 live 검색을 적용하고 출처를 포함한다.

## 구현 선택

- **실행 환경:** Python 3.12 이상, Textual 8.2.8, JSON Schema 검증은 jsonschema 4.26.0을 사용한다. 실행·개발 의존성의 고정 버전은 [pyproject.toml](../pyproject.toml)이 기준이다.
- **PDF·그림:** Playwright 1.63.0과 별도 로컬 설치한 Chromium을 사용한다. Mermaid 11.12.2, Noto Sans KR·Noto Sans Mono와 해당 라이선스를 패키지에 포함한다. 저장 자료를 렌더링할 때 CDN이나 폰트 다운로드를 요구하지 않는다.
- **초안 수정:** 제목·목표·학습 범위를 일반 텍스트로 수정하고, 파트는 `분 | 제목 | 목표; 목표` 형식으로 한 줄씩 편집한다. 시작한 과정의 계획은 고정하며 범위를 바꾸면 새 과정을 만든다.
- **모델·검색:** 앱은 모델명을 고정하거나 `--model`을 전달하지 않고 CLI 기본값을 사용한다. 검색은 기본 `cached`이며 최신 확인이 필요하면 실행 시 `--search live`를 선택한다.
- **재개:** 선택한 파트·섹션과 스크롤 위치, 문제별 답 메모, 정답 공개 여부를 저장한다. 완료한 과정도 파트 선택으로 다시 읽을 수 있으며 완료 상태를 바꾸지 않는다. 자료 재생성 실패는 이전 자료와 진행을 보존한다.
- **호출 검증:** 설치된 `codex-cli 0.160.1`의 ChatGPT 로그인과 작은 실제 비대화형 호출, 과정 초안, 전체 Lesson 생성·스키마 검증, 네이티브 이미지 생성·파일 수집이 성공했다. 언어 혼재 거부와 한국어 QA 교재의 저장·TUI 재개·한글 PDF 10페이지를 확인했다. 실제 생성과 고정 fixture의 구분은 [QA 기록](qa.md)에 있다.

## 확인 필요 사항

- 정식 이름은 미정이며 `study-tui`는 임시 작업명이다.
- 생성 교재의 구조·참조 검증은 사실 정확성을 보증하지 않는다. SQL 예제를 데이터베이스에 실행하거나 실제 학습 시간에 대한 사용자 실험은 하지 않았다. 최종 증거와 검증 경계는 [QA 기록](qa.md)에 있다.
- 실환경 검증 기준은 macOS arm64, Python 3.12.14, Codex CLI 0.160.1이다. Linux·Windows의 뷰어 호출과 자식 프로세스 정리는 별도 실환경 검증이 필요하다.
- 저장소는 2026-10-08 사용자 요청으로 공개했으며 프로젝트 코드에 [MIT 라이선스](../LICENSE)를 적용한다. 포함한 폰트·Mermaid의 라이선스는 해당 자산에 별도로 적용된다.

## 구현·검증 상태

2026-10-08 기준으로 Python/Textual 앱, Codex CLI 어댑터, SQLite·로컬 파일 저장, 사전 저장 후보 기반 시각자료 대체, 파트별 PDF와 고정 데모 교재를 구현했다. 최종 자동화 검증은 77개 테스트가 통과했다. 설치·실제 생성·TUI·PDF 확인과 수정 후 실제 화면 캡처와 [사용 안내](../README.md)를 작성했다. 세부 계약은 [상세설계](lld.md), 검증 증거와 지원 한계는 [QA 기록](qa.md)를 따른다.

저장소는 공개 상태이며 프로젝트 코드의 라이선스는 사용자 선택에 따라 MIT로 확정했다.
