# study-tui

소프트웨어 엔지니어가 하나의 백엔드 주제를 단계별로 공부하는 개인용 TUI 학습 도구입니다. DB 인덱스, 소프트웨어 디자인, 아키텍처 등을 다루며, `study-tui`는 정식 이름을 정하기 전의 임시 작업명입니다.

## 학습 흐름

주제 입력 → 범위·학습 목표 설정 → 파트별 자료·시각자료 생성 → 화면/PDF 열람·인쇄 → 퀴즈 풀이·정답 확인 → 사용자 복습/다음 선택 → 기본 과정 완료 → 선택한 심화 주제로 후속 학습

- 한 파트는 30~45분 분량이며 개념, 동작 원리, 실무 예시, 시각자료, 퀴즈를 포함합니다.
- 화면 열람과 인쇄용 PDF 내보내기는 필수입니다. 퀴즈 정답은 문제와 분리합니다.
- 기본 과정은 완료 지점이 있으며, 심화 학습은 사용자가 선택합니다.
- 퀴즈는 이해도 확인용입니다. 자동 채점이나 AI 답안 평가, 통과 조건은 없습니다.

## 현재 상태

요구사항, 협업 지침, Git 제외 규칙만 준비했습니다. 앱 코드, 실행 명령, 언어별 의존성은 아직 없습니다.

다음 단계는 구현 언어와 TUI 라이브러리, AI·검색 공급자, 비용 예산, PDF·시각자료 생성 방식을 정한 뒤 구현을 시작하는 것입니다. 별도 서버 없이 하나의 로컬 프로그램으로 구성하는 방안은 초안입니다.
