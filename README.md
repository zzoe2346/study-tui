# study-tui

소프트웨어 엔지니어가 하나의 백엔드 주제를 단계별로 공부하는 개인용 로컬 TUI 학습 도구입니다. DB 인덱스, 소프트웨어 디자인, 아키텍처 등을 다루며, `study-tui`는 정식 이름을 정하기 전의 임시 작업명입니다.

## 학습 흐름

주제 직접 입력 → AI 학습 목표·과정 초안 → 사용자 조정·시작 → 파트별 자료·시각자료 생성 → 화면/PDF 열람·인쇄 → 퀴즈 풀이·정답 확인 → 사용자 복습/다음 선택 → 기본 과정 완료 → 선택한 심화 주제로 새 과정

- 한 파트는 30~45분으로 개념, 원리, 실무 예시, 시각자료, 간단한 퀴즈를 포함합니다.
- 첫 버전 PDF는 파트별이며 정답·해설은 문제와 분리합니다.
- 진행을 저장해 중단 후 재개합니다. 심화 학습은 사용자가 선택합니다.
- 퀴즈는 이해도 확인용이며 자동 채점·AI 답안 평가·통과 조건이 없습니다.
- 앱 내부의 이력서 분석·주제 추천은 범위에 없습니다.

## 설계와 현재 상태

Python·Textual과 구독 인증을 사용하는 Codex CLI 연동을 기준으로 상세설계를 작성했습니다. 별도 HTTP 서버 없이 실행하며, AI 추론은 원격 Codex 서비스에 의존합니다.

SQLite·로컬 파일 저장과 HTML/CSS·Playwright 인쇄용 PDF는 LLD의 기본 설계입니다. Mermaid/SVG를 기본 시각자료로 두고 필요한 생성 삽화를 혼합합니다. CLI 이미지 기능 활성화는 확인했지만 비대화형 생성·산출물 수집은 구현 초기에 검증해야 합니다. 별도 유료 API로 자동 전환하지 않습니다.

현재는 문서만 있으며 앱 코드, 실행 명령, 의존성은 아직 없습니다. 다음 단계는 LLD의 확인 필요 항목을 검증한 뒤 최소 기능을 구현하는 것입니다.
